如果说 HTML 是网页的“骨架”，那么 CSS 就是网页的“皮肤和衣服”。颜色、字体大小、居中对齐、阴影、动画效果……这些全都是 CSS 负责的。

很多非技术人员觉得 CSS 很难，因为要记很多属性。现在有了 AI，你只需要描述“视觉效果”，AI 就会帮你翻译成 CSS 代码。

## 前提：你得先有 HTML

AI 需要知道你要美化什么东西。所以在让 AI 写 CSS 之前，你必须要把你的 HTML 代码发给它。

## 核心技巧：用“设计语言”向 AI 提要求

写 CSS 提示词时，尽量用具体的视觉描述词汇（如：圆角、阴影、渐变、居中、间距），而不是模糊的词汇（如：好看一点、高端一点）。

### 场景一：局部样式美化

假设你想美化一个按钮，你可以这样对 AI 说：

> “这是我的 HTML 按钮代码：`<button class="btn-primary">点击提交</button>`。
> 请帮我写一段 CSS，让它看起来更现代。
> **要求：**
> 1. 背景色用好看的蓝色渐变。
> 2. 字体变成白色，加粗。
> 3. 四个角变成圆角（大约8px）。
> 4. 添加一点柔和的底部阴影。
> 5. 鼠标悬停（Hover）时，按钮会稍微放大一点，背景色变深。”

### 场景二：整体页面布局（最难的部分）

新手最头疼的就是网页怎么排版（比如怎么把两张图片并排放在一起）。现在，你可以直接让 AI 用 Flexbox 或 Grid 布局来解决。

> 提示词：“下面是我的网页 HTML 代码。我现在想要进行排版设计。
> 请帮我写 CSS 代码，要求如下：
> 1. 网页整体背景为浅灰色，内容区域最大宽度为 1200px，并且在屏幕中水平居中。
> 2. 页面中类名为 `.card-container` 的区域，请使用 Flexbox 布局，让里面的卡片每行显示 3 个，卡片之间间距为 20px。如果屏幕变窄，自动换行。
> 
> [在此粘贴你的 HTML 代码]”

## 怎么把 CSS 用到网页上？

AI 生成了 CSS 代码后，有两种最常见的方法放到你的 HTML 里：

**方法 1：写在 HTML 文件的头部（适合新手练习）**
在你的 HTML 文件里，找到 `<head>` 标签内部，插入 `<style>` 标签，把 AI 给的 CSS 粘进去：
```html
<head>
  <style>
    /* 在这里粘贴 AI 生成的 CSS 代码 */
  </style>
</head>
```

**方法 2：外链文件（正规做法）**
新建一个 `style.css` 文件，把代码粘进去。然后在 HTML 的 `<head>` 里引入它：
`<link rel="stylesheet" href="style.css">`

## 小心 AI 的“过度设计”

有时候 AI 为了展示它的能力，会给你写一大堆冗长的动画和复杂的阴影，导致网页看起来很花哨或者运行卡顿。如果不喜欢，直接告诉它：“请去除花哨的动画，保持极简扁平化风格。”
