打开一些苹果或大厂的官网，你会发现随着鼠标向下滚动，文字和图片会丝滑地“浮现”出来，高级感满满。
其实，这些动效你自己的网站也能做！不用去啃复杂的 CSS 动画教程，用大白话向 AI 描述，它就能直接给你动画代码。

## 生成动画的基础准备

目前生成界面和动画效果出色大的 AI 工具是 [v0.dev](https://v0.dev) 和 [Claude](https://claude.ai)。
- 如果你是从零开始做一个带动画的组件，用 `v0.dev` 最方便。
- 如果你是想给现有的网页元素加动画，用 `Claude` 最准。

## 实操教程：用一句话写动画

### 场景一：给文字加上入场动画（淡入浮现）

如果你有一段文字，希望网页刚打开时它能优雅地出现。把你的文字所在的 HTML 代码复制给 AI。

**提示词示例：**
> “下面是我网站上的一个标题 `<h1 class="title">欢迎来到我的主页</h1>`。请帮我写一段纯 CSS 代码，要求：当网页加载时，这个标题从下方往上缓慢移动 20 像素，同时透明度从 0 变成 1，动画持续时间为 1 秒，效果要非常丝滑自然。请直接给我可以直接放在文件里的 CSS 代码。”

拿到代码后，粘贴到你的网站后台自定义 CSS 的地方，刷新页面，效果就出来了！

### 场景二：骨架屏加载动画

网页数据还没加载出来时，那种一闪一闪的灰色色块（骨架屏），非常提升用户体验。

**提示词示例：**
> “我要给一张还未加载出来的图片加一个‘呼吸闪烁’的占位动画。请用简单的 CSS 和 HTML 写一个 300x200 像素的灰色方块，要有平滑的呼吸渐变动画效果。”

### 场景三：生成滚动触发动画（进阶）

如果你希望页面滚动到某个位置时，内容才出现（而不是一打开就加载）。
> “我希望页面往下滚动到一段文字时，这段文字才从左边滑入。请用最简单的 HTML、CSS 和少量 JavaScript 帮我实现这个效果。代码尽量精简易懂，不需要引入第三方复杂的动画库。”

## 注意事项

- **切忌眼花缭乱**：动画是为了提升体验，而不是为了炫技。满屏幕的东西飞来飞去只会让访客头晕。
- **性能问题**：只对特定的元素做动画，不要让整个网页的背景都在复杂地移动，这会让低端手机卡顿。
- 不同地区、账号类型和平台政策可能存在差异，具体以工具当前官方页面显示为准。
