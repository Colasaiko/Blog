想要充分发挥 xAI 旗下人工智能 Grok 的潜力，掌握正确的提问方式（Prompt）至关重要。Grok 相比其他 AI 最独特的一点，在于它被设计得更具幽默感且较少受到传统内容的限制（“反叛”精神）。今天就来教你如何根据不同场景，写出最适合 Grok 的提示词。


## 一、这个功能是什么？

“Prompt（提示词）”就是你向 AI 输入的指令、问题或请求。它决定了 AI 会给你什么样的回答。对于 Grok 而言，Prompt 的写法不仅影响回答的准确度，还可以决定它是用“Fun 模式（幽默/讽刺）”还是“Regular 模式（正经/严肃）”来回答你。

## 二、在哪里可以找到？

只要你登录了 X (原 Twitter) 并订阅了 Premium 或 Premium+ 服务，就可以在网页版或移动端的中央导航栏找到 Grok 的专属入口。点击进入后，底部的文本输入框就是你输入 Prompt 的地方。在输入框附近，你通常可以找到切换“Fun Mode（趣味模式）”和“Regular Mode（普通模式）”的按钮。

## 三、怎么使用？

与 Grok 对话，写好 Prompt 的核心技巧可以总结为以下几点：

1.  **明确指定模式与基调**：
    虽然可以通过界面切换模式，但你也可以在 Prompt 中直接要求：“请用极度讽刺的语气回答”或“请非常严肃、专业地向我解释”。Grok 极其擅长捕捉这些语气词。
2.  **利用 X 平台的实时数据**：
    Grok 的一大优势是接入了 X 的实时推文流。你可以使用类似“根据今天 X 上的最新动态，总结...”的 Prompt，让它提供最新鲜的信息。
3.  **提供充足的上下文 (Context)**：
    像所有大模型一样，背景信息越多，回答越准。例如，与其问“怎么写 Python 代码？”，不如问“我正在写一个用于数据抓取的 Python 脚本，遇到了 XX 报错，请帮我分析原因并提供修复代码。”
4.  **分步骤提问 (Step by step)**：
    面对复杂问题，要求 Grok “请一步一步地推理”或者把大目标拆分成几个小请求，能显著降低它的出错率。
5.  **指定输出格式**：
    你可以明确告诉它：“请用表格对比”、“请输出 Markdown 格式”、“请用要点列表（Bullet points）总结”。

## 四、实际使用示例

**示例 1：发挥幽默特长（Fun Mode）**
*   **Prompt**: "以一个愤世嫉俗的程序员的口吻，向我解释什么是 '产品经理的敏捷开发'，尽量用一些比喻，字数在 300 字左右。"
*   *Grok 将会生成一段充满调侃、一针见血的吐槽式科普。*

**示例 2：获取实时资讯（Regular Mode）**
*   **Prompt**: "总结一下过去 24 小时内，关于 'SpaceX 星舰发射' 的最热门讨论，提取出 3 个最主要的新闻点，并保持客观专业的态度。"
*   *Grok 会调用实时推文，为你梳理出最准确的时效性信息。*

**示例 3：技术问题求解**
*   **Prompt**: "我是一名初级前端开发者。请帮我用 React 写一个倒计时组件。要求：1. 使用 Hooks (useState, useEffect)。2. 代码里加上详细的中文注释。3. 解释一下 useEffect 在这里的作用。"
*   *Grok 会切换到严谨模式，提供代码及清晰的讲解。*

## 五、常见问题

**Q: 为什么 Grok 的回答有时候像在开玩笑？**
A: 因为你可能正处于 Fun Mode，或者你的 Prompt 激发了它的幽默设定。如果需要正经答案，请在界面上切换回 Regular 模式，并在 Prompt 中加入“请严肃回答”。

**Q: Grok 可以读取我发给它的网页链接吗？**
A: 目前这取决于具体版本和 X 平台的限制。一般来说，Grok 更擅长抓取 X 平台内的实时链接和趋势。如果你想让它分析特定网页，优质的办法是将网页核心内容直接复制到 Prompt 中。

**Q: Prompt 越长越好吗？**
A: 不是。Prompt 应该是“信息密度高”的，而不是单纯的字数多。剔除废话，保留核心指令、背景信息和格式要求才是好 Prompt。

## 六、使用时需要注意什么？

1.  **区分事实与玩笑**：在 Fun 模式下，Grok 有时为了幽默可能会夸大其词，在涉及医疗、法律、财务等严肃话题时，务必切换到 Regular 模式并自行核实。
2.  **善用追问**：如果第一回答不满意，不要直接放弃。告诉它：“这个回答太简略了，请在这个段落补充更多细节”或者“语气有点不对，请重新用专业术语写一遍”。
3.  **隐私安全**：不要在 Prompt 中输入个人敏感信息（如密码、身份证号、内部机密代码等），所有输入给大模型的数据都有被用于后续训练的潜在风险。
