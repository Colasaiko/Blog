## 1. 简介

在配置 Mac 客户端时，我们通常会面临两种不同的接管模式：系统代理（System Proxy）和 TUN 模式。了解这两者的区别有助于根据不同的使用场景进行选择。

## 2. 系统代理 (System Proxy)

系统代理通过修改 macOS 系统网络设置中的代理配置，将 HTTP/HTTPS 及 SOCKS 流量导向客户端。

### 优点
- **兼容性好**：适用于绝大多数浏览器和遵循系统代理的常规应用。
- **开销极低**：由于是在应用层进行转发，系统资源消耗较少。

### 缺点
- **部分应用不生效**：一些终端工具或不遵循系统代理设置的软件无法被接管。

## 3. TUN 模式

TUN 模式会在系统层面创建一个虚拟网卡，将所有 IP 层的网络流量都截获并由客户端处理。

### 优点
- **全局接管**：无论是终端命令、游戏还是其他非标准应用，所有流量都能被接管。
- **防止 DNS 泄露**：可以更有效地处理 DNS 解析，避免污染。

### 缺点
- **资源消耗稍高**：需要在系统底层处理数据包。
- **需要较高权限**：首次开启通常需要管理员权限。

## 4. 总结

如果你主要使用浏览器，**系统代理**已经足够；但若你需要全局接管所有软件的流量，**TUN 模式**则是更佳的选择。
