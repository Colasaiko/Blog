Microsoft Copilot Agents (智能体) 是在 Copilot 体系中扮演特定领域专家的可定制 AI 助手。你可以赋予它们特定的指令和知识库，让它们在特定的工作流程中帮你自动执行任务、回答专业问题或处理繁琐的重复性工作。


## 一、这个功能是什么？

Copilot Agents 是 Microsoft 推出的可定制化 AI 助手，它允许用户或组织根据自身需求创建特定的 AI "员工"。
* **专属知识**：你可以给 Agent 上传特定的文档或连接到特定的数据源（如 SharePoint 文件夹或公司内部网站）。
* **自动化任务**：它可以根据设定的流程和触发条件，自动执行一些操作。
* **专业角色**：你可以让它扮演客服、数据分析师、HR 助手等特定角色，只专注于某项核心工作。
* **随时召唤**：在 Microsoft 365 各种应用（如 Teams、SharePoint、Word 等）中，可以直接召唤它来协助工作。

## 二、在哪里可以找到？

目前，你可以通过以下几个主要途径找到或创建 Copilot Agents：
1. **Copilot Studio**：这是 Microsoft 提供的核心创建平台，提供可视化的 Agent 构建界面。
2. **Microsoft 365 Copilot 界面**：在网页版或集成的应用界面中，通常会有 "Agents" 或 "智能体" 相关的标签页。
3. **Teams 等 M365 应用**：企业内部共享的 Agents 可以直接在 Teams 对话或 SharePoint 站点中找到并使用。

## 三、怎么使用？

使用和创建 Copilot Agents 通常包含以下步骤：
1. **明确目标**：确定你希望 Agent 解决什么具体问题。
2. **构建 Agent**（通过 Copilot Studio）：
   * **设定名称和描述**：让其他人清楚它是做什么的。
   * **编写指令 (Instructions)**：用自然语言告诉它应该如何表现，该做什么，不该做什么。
   * **提供知识库 (Knowledge)**：上传参考文档，或连接到公司内部数据库等。
   * **配置动作 (Actions)**：如果需要，可以连接外部 API 或配置流程，让它能实际执行操作（比如发邮件、建任务）。
3. **测试和发布**：在测试窗口与它对话，确认回答符合预期后，发布到 Teams 或其他渠道。
4. **日常调用**：在使用时，就像和普通人聊天一样向它提问或下达指令，它会基于你赋予的知识和能力进行回应。

## 四、实际使用示例

假设你要创建一个 "新员工入职向导" Agent：
* **指令**：“你是一个热情的 HR 助手，负责解答新员工关于入职流程、公司福利和 IT 配置的问题。请保持专业且友好的语气。如果遇到不知道的问题，请引导他们联系 HR 邮箱。”
* **知识源**：上传《员工手册.pdf》和《IT设备配置指南.docx》。
* **使用场景**：新员工在 Teams 里直接询问：“我怎么申请显示器？”，Agent 就会自动从 IT 配置指南中提取步骤并回复给员工。

## 五、常见问题

**Q1：创建 Agent 需要写代码吗？**
A：不需要。大部分基本的 Agent 都可以通过自然语言对话（Copilot 辅助创建）或简单的图形界面配置来完成，非常直观。

**Q2：Agent 的数据安全吗？**
A：Copilot Agents 遵循 Microsoft 365 的企业级安全和合规标准，数据不会用于训练公共大模型，并且严格遵循现有的数据访问权限控制。

**Q3：个人版 Copilot 可以用 Agents 吗？**
A：目前强大的定制和发布功能主要面向 Microsoft 365 Copilot（企业版）和 Copilot Studio 用户，个人版功能可能受到限制，具体视微软最新更新而定。

## 六、使用时需要注意什么？

* **指令要清晰**：给出的指示越具体，边界越明确，Agent 的表现越稳定。避免模糊不清的描述。
* **知识库质量**：Agent 的回答质量直接取决于你喂给它的数据，确保上传的文档是最新的且没有歧义。
* **持续迭代**：发布后，根据用户的真实反馈，不断回过头来修改它的指令和补充知识库。
