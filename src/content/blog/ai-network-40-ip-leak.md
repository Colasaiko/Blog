在访问海外 AI 工具（如 ChatGPT、Claude 等）时，你可能会遇到这样的情况：明明已经连接了代理节点，但网站依然无情地提示“您所在的国家/地区不可用”。甚至有的账号还会因此遭到封禁。这很大程度上是因为你的真实 IP 地址发生了泄露。

今天就来手把手教你如何检测 IP 泄露，以及该如何防范和修复这些问题。

## 为什么挂了代理还是会暴露真实 IP？

即使你使用了代理，一些隐蔽的技术机制依然能够绕过代理，获取你的真实网络环境信息：

1. **WebRTC 泄露**：WebRTC 是一项支持浏览器进行实时语音对话或视频对话的技术。它为了建立点对点连接，默认会暴露你的本地 IP 和真实公网 IP。
2. **DNS 泄露**：当你在浏览器输入网址时，需要将域名解析为 IP 地址。如果你的代理客户端没有正确接管 DNS 解析请求，这些请求可能就会发送给你本地的 ISP（网络服务提供商），从而暴露你的真实地理位置。
3. **浏览器指纹与时区**：现代浏览器会向网站提供非常详细的信息。如果你的系统时区（如东八区）和系统语言（中文）与你代理所在的节点 IP（如美国）产生明显的冲突，风控严格的 AI 网站就会判定你在使用代理。

## 如何检测 IP 是否泄露？

通过一些专业的在线检测工具，你可以直观地看到自己当前的网络是否“透明”。

### 推荐检测工具

*   **BrowserLeaks** (https://browserleaks.com/)：提供非常全面的浏览器隐私检测，包括 IP 地址、WebRTC、DNS 泄露以及浏览器指纹等。
*   **IPleak** (https://ipleak.net/)：专门用于检测 IP 和 DNS 泄露，页面直观易懂。
*   **Whoer** (https://whoer.net/zh)：会根据你的网络情况打出一个匿名得分，可以用来排查时区、语言和黑名单问题。

### 检测步骤

1.  开启你的代理工具，并选择全局模式或配置好相关路由规则。
2.  打开上述检测网站，查看显示的 IP 地址是否是你所选节点的 IP。
3.  重点检查 **WebRTC** 和 **DNS Addresses** 栏目。如果里面出现了你国内真实的 IP 或者是国内运营商的 DNS 节点，说明你已经发生了泄露。

## 如何修复 IP 泄露问题？

如果你发现自己存在泄露情况，可以按照以下步骤进行调整：

1.  **调整客户端路由与 DNS 设置**：确保你的代理客户端开启了“TUN 虚拟网卡模式”或严格的路由规则。同时，将 DNS 解析设置为通过代理进行（如使用远程 DNS）。
2.  **禁用浏览器的 WebRTC 功能**：
    *   可以通过安装浏览器插件（如 WebRTC Control）来一键禁用。
    *   在特定浏览器的高级设置中手动关闭（例如在 Firefox 中输入 `about:config` 并将 `media.peerconnection.enabled` 设为 `false`）。
3.  **使用无痕模式（Incognito）或独立浏览器**：对于重要的 AI 网站，建议使用浏览器的隐私无痕模式，以避免缓存和历史数据暴露身份。或者专门下载一个英文版、时区修改为目标国家、禁用 WebRTC 的独立浏览器，专用于访问 AI 服务。

## 常见问题 (FAQ)

**Q: 我只用网页版，还需要调整系统时区吗？**
A: 对于风控级别极高的网站（如初期的 ChatGPT 或者是 Claude），时区和语言不匹配是非常危险的信号。建议将系统时区修改为代理节点所在的时区，并尽可能使用英文系统。

**Q: 为什么我关了 WebRTC 还是被封号？**
A: 被封号的原因可能是多方面的。除了 IP 泄露，如果你使用的代理节点本身已经被许多人滥用过，或者节点 IP 已经被 AI 公司加入了黑名单，同样会导致无法访问或封号。建议寻找纯净度较高的独享 IP 或者原生 IP 节点。

**Q: 手机端也会出现 IP 泄露吗？**
A: 会的。手机端同样存在 DNS 泄露的风险。另外手机 App 可能会获取基站信息或 GPS 定位信息。因此访问网页版 AI 时同样需要做好防护。
