Poe 平台不仅汇集了各大主流的 AI 模型，更重要的是，它允许用户无需编写任何代码，只要通过设置提示词（Prompt）和上传知识库，就能轻松创建属于自己的个性化 AI 机器人（Bot）。今天就来带你一步步完成自定义 Bot 的创建，让你也体验一把当“AI 开发者”的乐趣。


## 一、这个功能是什么？

“创建 Bot” 是 Poe 提供的一项核心功能。它允许用户基于 Poe 平台上已有的基础模型（如 Claude 3、GPT-4o、Llama 3 等），通过预设特定的系统提示词（System Prompt）、上传自定义的参考文档（Knowledge Base）或设置欢迎语，来打造一个专注于特定任务或拥有特定人设的专属 AI 助手。你可以将创建好的 Bot 设为私有供自己使用，也可以公开分享给其他 Poe 用户。

## 二、在哪里可以找到？

1. 打开 Poe 的网页端或手机 App。
2. 在界面左侧的侧边栏（导航栏）的最上方，找到并点击 **“Create Bot”**（创建机器人）按钮。
3. 点击后即可进入 Bot 的创建与配置页面。

## 三、怎么使用？

创建专属 Bot 的过程非常直观，主要分为以下几个配置步骤：

1. **设置 Bot 图片和名称 (Handle)**：
   * 点击头像位置可以上传一张符合 Bot 人设的图片。
   * 在“Handle”中输入一个唯一的英文标识符（必须是没有被其他用户注册过的名称），这也会成为你 Bot 的分享链接后缀。

2. **选择基础模型 (Base bot)**：
   * 下拉选择一个你认为最适合的基础模型。比如，如果需要强大的逻辑分析，可以选择 GPT-4 或 Claude 3.5 Sonnet 的变体；如果只是日常对话，可以选择速度更快、更基础的模型（如 Claude 3 Haiku 或 ChatGPT）。**注意**：部分高级模型可能需要你的账号是 Poe 订阅用户才能作为基础模型提供无限制的对话，或者使用者会消耗更多的积分。

3. **设置提示词 (Prompt)**：
   * 这是赋予 Bot “灵魂”的最关键一步。在 Prompt 框中，详细写下你希望 Bot 扮演的角色、遵循的规则、回答的格式等。例如：“你是一位专业的英文翻译，请将我发送的所有中文内容翻译成地道、优美的英文，不需要解释翻译过程。”

4. **上传知识库 (Knowledge base)**：
   * 如果你需要 Bot 根据特定的资料回答问题（如公司手册、产品文档、个人笔记等），可以在此上传 PDF、TXT 等格式的文件。开启后，Bot 在回答时会优先参考这些上传的内容。你可以通过开关调整是否将该知识库设为每次回答的强制参考项。

5. **配置问候语 (Greeting message)**：
   * 设置一段开场白，当任何人打开你的 Bot 时，第一眼看到的就是这段话。它可以用来介绍 Bot 的功能，或引导用户如何提问。

6. **高级设置 (Advanced)**：
   * 这里可以设置是否允许模型推荐后续问题（Suggest replies），是否允许在全平台搜索（Search web），或者设置温度参数（Temperature，数值越高回答越有创造性，数值越低回答越严谨）等。

7. **保存并发布 (Create bot)**：
   * 将页面滑动到底部，设置 Bot 的可见性（Public 公开或 Private 私有），最后点击右下角的 **“Create bot”**。你的专属机器人就诞生了！

## 四、实际使用示例

**场景：创建一个“小红书爆款文案生成器”**

1. **名称 (Handle)**：xhs-copywriter-bot
2. **基础模型**：Claude-3.5-Sonnet（因为其文本创作能力较强）
3. **提示词 (Prompt)**：
   ```text
   你是一个资深的小红书运营专家。你的任务是根据用户给出的主题或产品，生成一篇符合小红书爆款风格的种草文案。
   要求：
   1. 标题要有吸引力，带有适当的Emoji。
   2. 正文部分采用“痛点+产品卖点+个人真实体验+行动号召”的结构。
   3. 语言风格要年轻化、有网感、多用短句和空行。
   4. 结尾加上合适的热门标签（Hashtags）。
   ```
4. **欢迎语 (Greeting message)**：
   “哈喽！我是你的小红书爆款制造机📝。请告诉我你想写什么产品或主题？如果有具体卖点也一并交给我吧！”
5. **创建完成后**：只要输入“一款适合干皮的平价防晒霜”，Bot 就会自动按照小红书的格式生成一篇高质量的排版文案。

## 五、常见问题

**Q: 创建 Bot 收费吗？**
A: 创建 Bot 本身是完全免费的。但是，如果你选择了某些高级的 Base bot（例如 GPT-4o 等），你需要有足够的 Poe 积分 (Compute points)，或者需要你是 Poe 订阅会员才能无限制使用。如果是公开的 Bot，其他用户使用它也会消耗他们自己的积分。

**Q: 为什么我设置了提示词，Bot 有时候还是会不听话？**
A: 提示词工程（Prompt Engineering）需要不断调试。尝试将你的指令写得更具体、明确，使用分点陈述，并明确告诉 Bot “不要做什么”。对于一些逻辑较差的小模型，遵守复杂 Prompt 的能力相对较弱。

**Q: 我上传的知识库安全吗？别人能看到原文件吗？**
A: 如果你的 Bot 是公开的，用户在对话时，Bot 会引用知识库中的内容，甚至可能被“套话”输出大段原文。因此，**千万不要上传包含个人隐私、公司机密或敏感信息的文档**。

## 六、使用时需要注意什么？

*   **经常测试与迭代**：刚创建的 Bot 往往不够完美。在保存前，你可以利用界面上的“Preview（预览）”功能测试对话。发布后，根据实际体验随时回到编辑页面修改 Prompt 和模型。
*   **字数限制**：System Prompt 和知识库的容量是有上限的，尽量提取最核心的指令和最纯净的文本数据，避免冗长的废话干扰模型的注意力。
*   **遵守平台规则**：无论是提示词还是知识库，都必须遵守 Poe 的社区准则，不要创建用于生成违规、暴力、色情等有害内容的 Bot，否则账号可能会被封禁。
