在日常使用 AI 的过程中，我们常常会遇到两种截然不同的需求：一种是希望 AI 能够记住我们的个人偏好和背景信息，免去每次都要重复解释的麻烦；另一种则是出于隐私考虑，希望进行一次“阅后即焚”的无痕对话。Poe 平台提供的 Memory（记忆）功能和 Temporary Chat（临时聊天）模式，正是为了满足这两种需求而设计的。


## 一、这个功能是什么？

**Memory（记忆功能）**：
记忆功能允许 Poe 中的特定机器人（如 Assistant、Claude 和 GPT 系列等）记住关于你的事实、偏好和之前对话中的细节。当开启此功能后，机器人在回答问题时会自动参考这些被记住的信息，从而提供更个性化、更贴合你需求的回应。

**Temporary Chat（临时聊天）**：
临时聊天是一种无痕对话模式。在这种模式下，你与机器人的对话不会保存在你的历史记录中，也不会被用于后续训练或产生记忆。一旦你关闭或离开该对话，内容就会立刻消失。

## 二、在哪里可以找到？

**Memory（记忆功能）**：
1. 打开 Poe 网页端或移动端，进入与某个机器人的对话界面。
2. 点击右上角的“信息”（i）图标或者直接在输入框上方查看是否支持记忆。
3. 你也可以在“设置”（Settings）界面中找到“Memory”（记忆）管理选项，集中查看和管理 AI 记住的所有内容。

**Temporary Chat（临时聊天）**：
1. 在与任何机器人对话时，点击界面上方的机器人名称进入详情菜单。
2. 在菜单中寻找“Temporary Chat”（临时聊天）或带有类似无痕浏览图标的选项。

## 三、怎么使用？

**如何使用 Memory（记忆功能）**：
1. **自动记录**：在正常的聊天过程中，如果你提及了个人信息（如“我是一名程序员”或“我喜欢简洁的回答”），支持记忆的机器人会自动提取并保存这些信息。
2. **主动告知**：你可以直接对机器人说：“请记住，我以后所有的代码示例都需要用 Python 编写。”
3. **管理与删除**：如果不想让机器人继续记住某条信息，可以进入“设置” > “记忆”，查看列表并手动删除特定条目，或者直接清空所有记忆。你也可以直接在对话中命令机器人：“忘记我刚才说过的关于XX的信息”。

**如何使用 Temporary Chat（临时聊天）**：
1. 点击启动“Temporary Chat”。
2. 此时界面通常会有视觉提示（如背景变暗或显示特定的图标），表明你已进入无痕模式。
3. 正常输入问题并进行对话。
4. 对话结束后，直接关闭该窗口即可，没有任何内容会被保留。

## 四、实际使用示例

**场景一：使用 Memory 定制写作风格**
- **你**：“请记住，我希望你以后的回答都尽量简短，并且不要使用复杂的专业术语。”
- **AI**：“好的，我已经记住您的偏好：回答简短且通俗易懂。”
- *（在未来的对话中，该机器人都会自动遵循这个设定。）*

**场景二：使用 Temporary Chat 咨询敏感问题**
- **你**：（开启临时聊天）“我想了解一下某种特定疾病的初步症状，不希望这被记录下来。”
- **AI**：*（提供相关科普信息）*
- *（关闭窗口后，这段涉及个人健康隐私的对话将彻底从你的账号中消失。）*

## 五、常见问题

1. **所有的机器人都支持 Memory 吗？**
   并非所有机器人都支持。目前主要是 Poe 官方提供的核心机器人（如 Assistant、GPT-4、Claude-3 等）支持记忆功能，部分由用户创建的第三方机器人可能尚未启用。
2. **临时聊天中的消息真的极少不会被保存吗？**
   对于用户端来说，历史记录中极少不会出现。但为了防止滥用，平台可能会在服务器端进行极短时间的加密留存以做安全审核，具体请参考 Poe 的隐私政策。
3. **如何关闭机器人的记忆功能？**
   如果你不希望机器人再产生新的记忆，可以在机器人的设置页面或系统全局设置中将“Memory”选项切换为关闭状态。

## 六、使用时需要注意什么？

1. **隐私安全**：尽管有记忆功能，仍不建议向 AI 提供诸如银行卡号、密码、身份证号等极其敏感的个人数据。
2. **定期清理**：随着时间推移，AI 可能会记住大量零碎信息，甚至有些信息已经过时。建议定期去“设置”中检查并清理无用的记忆，以免影响后续回答的准确性。
3. **临时聊天的局限性**：由于临时聊天不会保存上下文，如果你意外刷新了网页或退出了应用，正在进行的对话将无法找回，因此不适合进行需要长时间、多步骤推演的复杂任务。
