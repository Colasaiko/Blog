打开 Clash 后发现国内 App 加载变慢、外卖定位飘到海外，或者部分学术外网依然打不开？这些常见困扰绝大多数都与当前选择的「代理模式」直接相关。掌握规则模式、全局模式与直连模式的正确切换方法，是实现国内外网络无感分流的关键。

这些问题其实都与 Clash 的**代理模式（Proxy Mode）**息息相关。

如果把你的电脑发出的所有网络请求比作**源源不断的出城车流**，那么 Clash 的代理模式就是**城市交通枢纽的智能调度中心**。它是决定这辆车该走“本地高速公路”（国内直连）、还是该被送往“国际集装箱港口”（代理节点中转），亦或是直接“原路拦截”（广告拦截）的核心决策机制。

今天就来为你全面拆解 Clash 的各种代理模式，手把手教你如何正确切换模式，以及在不同使用场景下如何做出最优选择。

---

## 基本概念

在绝大多数 Clash 客户端（如 Clash Verge Rev、Clash Nyanpasu、Clash for Windows、Clash Meta 等）的主界面顶部或设置中，你都会看到几个模式选项：**Rule（规则）**、**Global（全局）**、**Direct（直连）** 以及进阶的 **Script（脚本）**。

```
                       ┌─────────────────────────┐
                       │   Clash 核心代理模式    │
                       └────────────┬────────────┘
         ┌──────────────────────────┼──────────────────────────┐
         ▼                          ▼                          ▼
 ┌───────────────┐          ┌───────────────┐          ┌───────────────┐
 │   规则模式    │          │   全局模式    │          │   直连模式    │
 │    (Rule)     │          │   (Global)    │          │   (Direct)    │
 ├───────────────┤          ├───────────────┤          ├───────────────┤
 │ 智能分流分拣  │          │ 一刀切全代理  │          │ 全放行不代理  │
 │ 国内直连/国外走节点 │      │ 容易误伤国内应用 │       │ 相当于暂时停用 │
 └───────────────┘          └───────────────┘          └───────────────┘
```

### 1. 规则模式（Rule）—— 智能交通指挥官（推荐日常默认）
- **工作机制**：Clash 会依据配置文件中预设的成千上万条分流规则库（Domain、IP-CIDR、GeoIP 等），对每一个网络连接进行实时“身份证核验”：
  - 识别为**国内域名/IP**（如 百度、淘宝、微信、Bilibili）：直接走本地网络连接（`DIRECT`），不耗费代理流量，速度最快、延迟最低。
  - 识别为**海外/受限网站**（如 Google、YouTube、GitHub、ChatGPT）：自动转发给指定的代理节点（`PROXY`）进行科学中转。
  - 识别为**广告与追踪域名**：直接予以拒绝阻断（`REJECT`），起到净化网页的作用。
- **优点**：智能省心、无感切换、节省流量、国内应用不弹异地登录警告。

### 2. 全局模式（Global）—— 一刀切全部出国
- **工作机制**：无视任何分流规则列表，将你设备产生的所有网络访问请求（无论国内还是国外），通通强制打包通过你在 `GLOBAL` 策略组中选定的海外节点发送出去。
- **优点**：简单粗暴，适合访问某些小众、冷门且尚未被规则库收录的海外网站。
- **缺点**：国内网站（如腾讯视频、网易云音乐）可能因识别为“海外 IP”而出现版权受限打不开；微信、支付宝可能触发异地安全风控；且国内大文件下载会剧烈消耗节点流量。

### 3. 直连模式（Direct）—— 彻底放行不接管
- **工作机制**：所有流量一律直接连接目标服务器，完全不走任何代理节点。
- **作用**：等同于“暂时关闭了代理转发功能”，常用于排查本地宽带故障，或者测试某个网站在没有代理介入时的原始网络表现。

### 4. 脚本模式（Script）—— 极客专属编程分流
- **工作机制**：允许用户使用 Python 或 JavaScript 代码编写复杂的条件判断逻辑（如根据时间、进程名、特定端口来动态分配出口）。
- **适用人群**：仅适合网络工程师或有高级定制需求的用户，普通新手无需使用。

## 进一步理解

理解了三大模式的定义后，我们需要进一步探究日常使用中的核心机制与配套功能。

### 1. 为什么“规则模式（Rule）”是绝大多数人的标准答案？
很多新手误以为“全局模式肯定加速得更彻底”，但事实恰恰相反。

现代互联网服务具有极强的本地化分发（CDN）属性。例如你访问国内的淘宝或优酷，如果处于“规则模式”，请求走本地光纤直接连到同城的 CDN 边缘节点，延迟仅需 5ms；但如果你开启了“全局模式”，请求必须先飞往日本或美国的节点服务器，再由海外服务器跨国请求国内网站，延迟会暴增到 200ms 以上，体验极差。

因此，**规则模式是兼顾“国内服务极速直连”与“海外服务顺畅出海”的唯一平衡点**。

### 2. 系统代理（System Proxy）与 TUN 虚拟网卡模式
切换代理模式时，通常还会涉及底层流量接管的方式：
- **系统代理（System Proxy）**：修改操作系统的网络代理设置（在 Windows/macOS 中配置 127.0.0.1 端口）。它能接管 90% 的主流网页浏览器与常用软件，但无法接管部分不支持系统代理的命令行终端（CMD/Terminal）、游戏客户端或后台服务。
- **TUN 虚拟网卡模式**：在操作系统内核层创建一张虚拟网卡，强制捕获整台电脑发出的所有网络数据包（包括 UDP 游戏流量、Git、Docker 等），配合【规则模式】，能够做到真正的全系统“无死角分流”。

## 实际应用

### 1. 各主流客户端如何切换代理模式？

#### 方式 A：现代客户端（Clash Verge Rev / Clash Nyanpasu）
1. 打开客户端主界面。
2. 在左侧菜单栏或顶部导航栏中，找到 **“模式”（Mode）** 区域。
3. 界面上会直观地显示 `[规则 (Rule)]`、`[全局 (Global)]`、`[直连 (Direct)]`、`[脚本 (Script)]` 四个按钮。
4. 鼠标直接点击相应模式，按钮高亮即表示切换成功。
5. **注意**：如果切换到了【全局模式】，请务必移步到 **“代理 (Proxies)”** 界面，在顶部出现的 `GLOBAL` 组中点选你希望指定的具体节点。

#### 方式 B：经典客户端（Clash for Windows / CFW）
1. 点击左侧导航栏的 **“Proxies”（代理）**。
2. 在界面顶部可以看到 **Rule / Global / Direct / Script** 四个切换标签。
3. 单击切换即可完成生效。

```
┌──────────────────────────────────────────────────────────────┐
│  [ Rule (规则) ]    [ Global (全局) ]    [ Direct (直连) ]   │ <--- 点击切换
├──────────────────────────────────────────────────────────────┤
│  Proxy Group (代理策略组)                                      │
│  ├─ 🚀 节点选择   [ 香港 01 IPLC ]   [ 日本 02 BGP ] ...       │
│  ├─ 🤖 OpenAI     [ 美国 01 原生 ]   [ 新加坡 02 ] ...         │
│  └─ 🎯 国内直连   [ DIRECT ]                                  │
└──────────────────────────────────────────────────────────────┘
```

### 2. 场景化实战决策指南

| 使用场景 | 推荐模式 | 操作建议与理由 |
| :--- | :--- | :--- |
| **日常刷网页、看 YouTube、日常办公** | **规则模式 (Rule)** | 保持默认即可。国内网站不走代理，海外网站自动中转，两全其美。 |
| **访问冷门海外小站显示 404 或超时** | **全局模式 (Global)** | 临时切到全局模式，并在 `GLOBAL` 组选一个美国/日本节点刷新重试。访问完毕后切回规则模式。 |
| **某国外服务刚上线，规则库未更新** | **全局模式 (Global)** | 新产品（如某些新发布的 AI 工具）域名未被机场订阅内置规则识别，全局模式可强制代理。 |
| **怀疑网络异常，需测试本地裸连状态** | **直连模式 (Direct)** | 切换为直连模式以测试本地宽带是否畅通，排除代理配置引起的干扰。 |
| **玩外服 Steam 游戏 / 命令行开发拉取代码** | **规则模式 + TUN 模式** | 保持规则模式，同时开启客户端内的 **TUN Mode**（需管理员权限），实现全协议游戏/终端加速。 |

## 常见误区

### 误区 1：切到了全局模式（Global），却依然打不开被墙网站
- **排查原因**：切换到全局模式后，Clash 会开启一个独立的 `GLOBAL` 策略组。许多新手切了全局，却忘了在 `GLOBAL` 组内选定具体的有效节点，导致出口节点依然停留在失效节点或 `DIRECT` 上。

### 误区 2：长期开着“全局模式”不关
- **后果**：
  1. 你的国内手机银行、网银 App 可能会因检测到海外 IP 频繁弹出安全风险警告甚至限制转账。
  2. 微信朋友圈图片和视频加载变卡，打微信视频通话出现延迟。
  3. 你的机场订阅流量在不知不觉中被国内网盘同步、系统更新消耗殆尽。

### 误区 3：以为“直连模式”就是彻底退出了 Clash
- **真相**：直连模式下，Clash 内核仍在后台运行，系统代理端口依然处于监听状态，只是把所有流量转发策略强制设为 `DIRECT`。如果想要彻底卸载代理环境，应该在客户端中关闭 **“系统代理（System Proxy）”** 开关并退出软件。

## 总结

掌握 Clash 的代理模式切换，是玩转网络代理与高效网络管理的基础基本功：

1. **日常 99% 的时间**：始终使用 **【规则模式（Rule）】**，省心、极速且不浪费流量。
2. **遇到海外特殊网站无法加载时**：临时切换为 **【全局模式（Global）】** 进行排查，并在 `GLOBAL` 组确认选中了健康节点。
3. **遇到全网络不通或需排查本地网络故障时**：可切为 **【直连模式（Direct）】** 对比测试。
4. **游戏加速与终端开发**：采用 **【规则模式 + TUN 虚拟网卡】** 组合方案。

理清这套逻辑，你就能在复杂的网络世界中游刃有余，畅享无缝顺滑的上网体验！
