在 Clash、Shadowrocket 等代理软件中，**规则模式（Rule Mode）**是绝大多数人日常挂机首选的工作方式。它能够像智能交警一样，自动让国内网站走本地直连、让被屏蔽的海外网站走代理隧道，既不浪费机场流量，也完全不影响国内应用的访问速度。

简单来说，规则模式就像是一个拥有高度智能的“网络交通警察”，它能够根据你提前设定好的规则，对你设备上发出的所有网络请求进行精准的分流指挥。今天，我们就来深入浅出地聊聊，到底什么是规则模式，它为什么如此重要，以及我们该如何更好地利用它。

## 基本概念

“规则模式”（Rule Mode）顾名思义，就是按照特定的“规则”来决定每一个网络请求应该怎么走。

在我们日常上网时，设备会发出成千上万的网络请求。比如，当你在浏览器中输入 `baidu.com`，或者打开微信回复消息，亦或是点开 YouTube 观看视频，这些行为都会产生网络数据包。

如果你身处中国大陆，那么你面临的网络环境是极其特殊的：
1. 一部分网站（如淘宝、微信、百度）是国内服务器，可以直接快速访问。
2. 另一部分网站（如 Google、YouTube、Twitter）位于海外，因为众所周知的原因，直接连接是无法访问的，必须通过代理服务器才能正常浏览。
3. 还有一部分网站（如某些海外学校的官网或小众国外网站）虽然没有被墙，但直接访问速度非常慢，或者我们更希望通过代理来加速访问。

在没有规则模式的情况下，你要么把所有流量都送到代理服务器（全局模式），这会导致访问国内网站变得很慢，而且白白浪费了宝贵的代理流量；要么都不走代理（直连模式），这就导致无法访问外网。

**规则模式的出现，就是为了完美解决这个痛点。** 在规则模式下，代理客户端会读取一份预先写好的“规则列表”。当设备发起一个网络请求时，客户端会拿着这个请求的目标地址去规则列表中进行匹配：
- 如果规则说这个网址是国内的，就让它**直接连接**（Direct）。
- 如果规则说这个网址是被墙的海外网站，就把它丢给**代理服务器**（Proxy）。
- 如果规则说这个网址是要拦截的广告，就直接**拒绝连接**（Reject）。

这就是规则模式最核心的基础概念：**按需分配，精准导向**。

## 进一步理解：规则模式是如何工作的？

要更深入地理解规则模式，我们需要知道它是如何进行“匹配”的。这就像交通警察在查车，他需要依据某些特征来决定放行还是拦截。常见的匹配依据有以下几种：

### 1. 基于域名的匹配（DOMAIN）
这是最常见的一种规则。域名就是我们常说的网址后缀，比如 `google.com` 或 `taobao.com`。
- **全域名匹配（DOMAIN）**：严格要求请求的域名和规则一模一样。比如规则写了 `DOMAIN,www.google.com,Proxy`，那么只有精确访问 `www.google.com` 才会走代理，访问 `mail.google.com` 就不会触发这条规则。
- **域名后缀匹配（DOMAIN-SUFFIX）**：只要域名的结尾匹配即可，这是最实用的一种。比如 `DOMAIN-SUFFIX,google.com,Proxy`，这意味着不论是 `www.google.com` 还是 `maps.google.com`，甚至 `abc.def.google.com`，只要是以 `google.com` 结尾的，统统走代理。
- **域名关键字匹配（DOMAIN-KEYWORD）**：只要域名中包含指定的关键字就触发规则。比如 `DOMAIN-KEYWORD,google,Proxy`，任何包含 google 字母的网址都会走代理。

### 2. 基于 IP 地址的匹配（IP-CIDR）
有时候域名匹配不够用，或者某些应用直接使用 IP 地址进行通信（如 Telegram），这时就需要基于 IP 来制定规则。
- 比如规则规定：目标 IP 是 `91.108.4.0/22`（Telegram 的服务器 IP 段），则走代理。
- 比较常见的还有：`GEOIP,CN,Direct`，这代表利用 GeoIP 数据库判断，只要目标 IP 的地理位置属于中国大陆（CN），就统统直连。这是防止国内应用误走代理的一道重要防线。

### 3. 基于进程的匹配（PROCESS-NAME）
在 Windows 或 macOS 等桌面端操作系统中，Clash 可以识别出是哪个软件（进程）发出的网络请求。
- 比如你可以设置：`PROCESS-NAME,Telegram.exe,Proxy`，这就意味着只要是 Telegram 这个软件发出的所有请求，不管它访问什么网址或 IP，全部走代理。这种方式对付那些不讲理的客户端软件非常有效。

### 客户端的处理流程
当你在规则模式下打开一个网页时，客户端会在后台进行极速的运算：
1. 拦截浏览器的请求。
2. 从上到下依次核对规则列表。
3. 一旦命中某条规则，立即按照该规则指定的策略（如直连、代理、或指定的代理节点组）去执行。
4. 如果找遍了所有的规则都没有匹配上，就会执行最后一条“兜底规则”（通常叫做 `MATCH` 或 `FINAL`），一般来说，兜底规则会被设置为走代理，以防有些未收录的海外小众网站无法访问。

## 实际应用：规则模式带来的好处

规则模式之所以成为绝大多数人的默认选择，是因为它在实际应用中带来了无可替代的优势。

### 1. 极致的体验：国内直连，国外代理
这是规则模式最直观的好处。你不需要再像早些年使用传统 VPN 那样，看国外网站时打开 VPN，看国内视频时又赶紧关掉 VPN。在规则模式下，你完全可以 24 小时开着 Clash 等代理软件。你聊微信、看 B 站、点外卖的流量全部不经过代理服务器，速度飞快且不耗费代理流量；而当你随时切到 YouTube 或 Google 时，流量又会自动通过代理服务器，无缝衔接。这种“无感代理”的体验是极其舒适的。

### 2. 节省流量与降低成本
绝大多数的机场（代理服务提供商）都是按流量计费的。如果不使用规则模式（比如使用全局模式），你下载一部几十 GB 的国内电影，或者在手机上更新几个国内 App，不知不觉中就会把套餐内珍贵的几十 G 代理流量全部耗尽。而规则模式完美地将大流量的国内请求分流到了直连，大幅度节省了你的代理流量。

### 3. 去除广告与隐私保护
前面提到过，规则不仅可以设定为“直连”或“代理”，还可以设定为“拒绝”（Reject）。许多优秀的规则维护者会在规则集中加入大量的广告追踪域名和恶意软件域名。当这些域名被规则模式识别并分配给 `Reject` 策略时，这些广告请求就会被直接在本地阻断。这不仅能屏蔽网页和 App 内的广告，还能保护你的隐私，避免被各种追踪器收集数据。

### 4. 解决国内软件封号和异地登录风险
许多国内的软件（如微信、支付宝、银行 App、甚至一些游戏）对 IP 地址变化非常敏感。如果你使用全局模式，你的 IP 会瞬间变成美国、日本或新加坡，这极容易触发这些软件的风控系统，导致账号被冻结或需要繁琐的验证。规则模式确保了这些国内软件的流量永远通过你真实的本地 IP 发出，从根本上杜绝了这类风险。

## 常见误区

虽然规则模式非常强大，但在使用过程中，新手往往会陷入一些误区，导致体验下降。

### 误区一：规则越多越好，越全越好
有些用户喜欢去网上找那种包含了成百上千甚至上万条规则的“超级规则库”，认为规则越全，分流就越精准。实际上这是一个大错特错的观念。
每一条网络请求都需要经过规则库的匹配，如果规则库极其庞大，会大大增加设备的 CPU 计算负担，导致网络延迟升高，手机耗电增加。优秀的规则通常是“精简而高效”的，多使用大范围的 `GEOIP` 或广泛的域名后缀匹配，而不是穷举每一个子域名。

### 误区二：规则模式下网速变慢是节点的问题
有时你会发现，开启规则模式后，访问国内某些原本很快的网站变慢了。这往往不是代理节点的问题，而是你的**规则配置不当**或者**DNS 设置出了问题**。
如果规则没有正确地将该国内网站判定为直连，或者你的客户端在解析国内域名时使用了国外的 DNS 服务器，就会导致解析结果绕了远路。因此，选择一份靠谱、有专人维护的规则集（如常见的 ACL4SSR 规则）是非常重要的。

### 误区三：为什么有的国外网站在规则模式下打不开？
当遇到某个国外小众网站打不开，但切换到“全局模式”就能打开时，很多新手会一头雾水。原因很简单：这个小众网站的域名没有被收录在你的规则列表里，同时你的“兜底规则（FINAL）”被设置成了“直连”。
这时候，如果你懂一点点原理，就可以手动把这个网站的域名加入到你的自定义规则中，并指向 Proxy，以后就能畅通无阻了。

## 如何判断与如何选择？

在日常使用中，你应该如何判断自己是否需要使用规则模式呢？

**答案是：在 99% 的日常使用场景中，你都应该毫不犹豫地选择“规则模式”。**

**你应该选择规则模式，如果：**
- 你希望 24 小时挂着代理，不想来回手动开关。
- 你同时需要访问国内网络和海外网络。
- 你的代理套餐流量有限，不想被国内视频、下载等消耗掉。
- 你在手机上使用，希望国内的微信、支付宝等 App 正常工作不被风控。

**但在以下极少数特殊情况下，你可能需要暂时离开规则模式，切换到全局模式：**
- 当你在规则模式下发现某个海外网站死活打不开，想临时测试是不是被墙了。
- 你在玩某些外服游戏，由于游戏服务器 IP 繁多且未被规则收录，需要强制全局代理来保证连接。
- 你所在的网络环境（如严格的公司内网或某些特殊的校园网）屏蔽了大量的国内常用端口，你需要把所有流量伪装成代理流量发出去。

## 总结

“规则模式”可以说是现代代理客户端的灵魂所在。它通过一套聪明的“交通管制”系统，让国内的数据走国内的高速公路，让海外的数据走代理的专属隧道，甚至顺手把路上的广告垃圾给清理掉。

对于普通用户来说，你不需要自己去从头编写这一行行的规则。现在绝大多数的机场提供的订阅链接中，都已经内置了非常完善且成熟的规则集（比如著名的 Clash 预设配置）。你只需要在客户端（如 Clash for Windows 或 ClashX）的面板上，确认勾选了**“Rule”或“规则”**，然后就可以享受那种忘记代理存在、丝滑畅游整个互联网的美妙体验了。

掌握了规则模式的概念，你就跨过了代理加速的第一个重要门槛。在下一篇文章中，我们将继续探讨与之对应的“直连模式”，看看它又在什么场景下发挥着独特的作用。
