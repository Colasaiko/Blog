做网站最让人抓狂的时刻是什么？——“为什么这个按钮点不动？”、“为什么手机上看文字全挤在一起了？”

这些网页里的错误，俗称 Bug。以前找 Bug 需要一行一行看代码，现在有了 AI，你只需要把症状告诉它，它就能当赛博老中医，精准把脉并开出药方。

## 准备工作

如果网页出了问题，不要慌。你需要准备两样东西：
1. **出错的表现**：比如“点击提交按钮页面就白屏了”。
2. **出问题的代码**：或者出错页面的截图。

推荐使用的工具：[Cursor](https://cursor.sh)（适合有代码文件的网站）或 [ChatGPT](https://chat.openai.com)（适合直接粘贴代码）。

## 排查 Bug 的三板斧

### 1. 描述症状，让 AI 锁定问题
不要指望 AI 自己去网站上乱逛找 Bug，你必须精准描述问题。

**向 AI 提问的模板：**
> “我在网页中遇到了一个问题。表现是：**[当我在手机浏览器打开时，底部的图片超过了屏幕宽度，导致页面可以左右滑动]**。
> 下面是相关的 HTML 和 CSS 代码，请帮我找出是哪行代码导致的问题，并给出修复后的代码：
> [粘贴你的代码]”

### 2. 巧用浏览器控制台（Console）
如果网页上的按钮点了没反应，通常是 JavaScript 报错了。
1. 在浏览器里按 `F12`，点击 `Console`（控制台）标签页。
2. 你会看到一些红色的错误代码（不用看懂）。
3. 直接把这些红色的错误信息复制，丢给 AI：
> “我的网页报错了，控制台显示：`Uncaught ReferenceError: $ is not defined`。请问这是什么原因？我该怎么解决？”
AI 会立刻告诉你，这是因为你没有引入 jQuery 库，并教你如何加一行代码解决。

### 3. 使用 Cursor 的智能修复
如果你用 Cursor 打开了网站文件夹，甚至都不用自己找代码在哪。
直接在侧边栏聊天框问：“为什么首页的轮播图不会自动播放了？”
Cursor 会自动扫描你的所有文件，找出轮播图对应的 JavaScript 文件，指出哪里写错了，并提供一个 `Apply`（应用）按钮，点击就能自动修改好。

## 常见排坑
- **描述不清**：只说“网页坏了”AI 是无法帮你的，一定要说清楚是在哪个浏览器、点击了什么、看到了什么错误。
- **改出一个新 Bug**：如果 AI 给的代码没用，甚至带来了新问题，直接告诉它：“你的代码没用，不仅问题没解决，反而连背景颜色都消失了，请重新检查。”
- 不同地区、账号类型和平台政策可能存在差异，具体以工具当前官方页面显示为准。
