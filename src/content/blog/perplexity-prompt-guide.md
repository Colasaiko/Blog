想要在使用 Perplexity 时获得更精准、更有深度的回答，关键在于你如何向它提问，也就是如何编写 Prompt（提示词）。合理的提问技巧能够激发 Perplexity 更强大的检索和整合能力。


## 一、这个功能是什么？

Prompt（提示词）是你向 AI 系统发出的指令或问题。在 Perplexity 中，Prompt 决定了它搜索的广度、深度以及最终呈现给你的内容形式。由于 Perplexity 是一个结合了实时网络搜索和 AI 大模型理解能力的“对话式搜索引擎”，一个好的 Prompt 不仅能让它知道“找什么”，还能告诉它“怎么分析”和“怎么总结”。

## 二、在哪里可以找到？

在 Perplexity 的任何界面中，只要看到输入框（如首页的 "Ask anything..." 或对话页面底部的输入栏），这就是你输入 Prompt 的地方。在输入过程中，你还可以结合 Focus（聚焦搜索）、Attach（上传附件）和 Pro 模式来增强提问的效果。

## 三、怎么使用？

编写高效的 Perplexity Prompt，可以参考以下几个核心公式和技巧：

1. **明确目标（核心）**：直接说明你想要了解的问题，避免过于宽泛。例如，“解释量子力学”不如“用小学生能听懂的话，结合生活中的例子解释量子力学”。
2. **设定角色与背景**：告诉 AI 它应该以什么身份来回答，或者提供问题所处的背景。例如：“作为一名资深数据分析师，请帮我分析……”
3. **指定输出格式**：如果你需要特定的格式，直接在 Prompt 中要求。比如：“请用 Markdown 表格对比 A 和 B 的优缺点”、“请用 3 个要点总结”。
4. **善用“Focus（聚焦）”功能**：如果你只需要学术论文的内容，或者只要 YouTube 视频，可以在提问前通过 Focus 选择特定的内容源。
5. **开启 Pro 模式**：遇到复杂问题时，开启 Pro 模式（原 Copilot），Perplexity 会主动向你提问以澄清意图，然后进行深度多步搜索。

## 四、实际使用示例

这里列举几个不同场景下的提问示例：

* **资料收集与对比**：
  > “请帮我对比目前市面上主流的三款降噪耳机（索尼 WH-1000XM5、Bose QC45、苹果 AirPods Max），从价格、降噪效果、佩戴舒适度三个维度进行对比，并用表格呈现。”
* **学习新知识**：
  > “我是一名 Python 初学者，请解释什么是‘面向对象编程’，要求用生活中的类比来说明，并给出一段简单的 Python 示例代码。”
* **长文总结与分析**：
  > “查找关于‘2025年人工智能发展趋势’的最新报告，并总结出三个最重要的趋势，每个趋势下附带一个具体的行业应用案例。”
* **解决技术问题**：
  > “我的电脑是 Windows 11，在运行某软件时提示‘缺少 dll 文件’，请列出可能的原因和一步步的修复方案。”

## 五、常见问题

**1. 为什么 Perplexity 给出的答案很短？**
这通常是因为你的 Prompt 过于简单，或者没有要求它提供详细解释。尝试在 Prompt 中加上“请详细说明”、“请列举至少三个原因”等限定词。

**2. 它可以处理非英文的提问吗？**
完全可以。Perplexity 支持多语言，你用中文提问，它就会用中文搜索并整合结果回答你。

**3. Pro 模式和普通搜索提问有什么区别？**
普通搜索会直接根据你的 Prompt 给出一次性的结果；而在 Pro 模式下，如果你的问题不够明确，Perplexity 会反问你以获取更多细节，然后进行多步骤、多视角的深度检索。

## 六、使用时需要注意什么？

* **避免含糊其辞**：AI 不是读心者，指令越清晰，结果越准确。
* **不要一次性问太多问题**：如果问题非常复杂，建议拆分成几个小问题，在一个 Thread（对话）中分次提问。
* **核实信息来源**：虽然 Perplexity 会提供引用的脚注（Citations），但在处理重要决策或专业性极强的内容时，建议点击脚注链接核实原文。
