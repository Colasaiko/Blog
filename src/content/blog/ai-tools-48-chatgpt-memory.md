在日常使用 ChatGPT 的过程中，你是否觉得它越来越“懂”你？当你让它写邮件时，它自动使用了你的语气；当你问它食谱时，它主动避开了你过敏的食材。这一切都归功于 ChatGPT 的**记忆功能（Memory）**。

今天就来带你全面了解 ChatGPT 的记忆功能，并教你如何高效管理和使用它，打造一个完全符合你习惯的专属 AI 助理。

## 什么是 ChatGPT 的记忆功能？

ChatGPT 的记忆功能（Memory）允许 AI 在与你的多次对话中记住特定信息。与“自定义指令（Custom Instructions）”需要你手动设置全局规则不同，Memory 是动态且持续更新的。

它可以通过两种方式形成记忆：
1. **自动提取**：在日常对话中，ChatGPT 会自动识别并记住关于你的重要信息（如职业、偏好、习惯等）。
2. **主动告知**：你可以直接命令 ChatGPT 记住特定的事情。

## 如何主动让 ChatGPT 记住你的偏好？

你可以像吩咐私人助理一样，直接在对话框中告诉它需要记住的内容。以下是一些常见的应用场景和提示词示例：

### 1. 编程习惯与代码风格
如果你是一名开发者，你可以让 ChatGPT 记住你的技术栈和代码风格。
*   **提示词示例**：“记住：我主要使用 Python 和 React。在给出代码示例时，请默认使用 ES6 语法，并加上详细的中文注释。”

### 2. 写作风格与语气
你可以让 ChatGPT 记住你的职业身份和写作偏好。
*   **提示词示例**：“记住：我是一名产品经理，我写邮件的风格是简明扼要、直接说重点，不要使用过多的客套话。”

### 3. 生活习惯与饮食禁忌
如果你经常用 ChatGPT 规划生活，这非常有用。
*   **提示词示例**：“记住：我对花生过敏，而且我是一名素食主义者。以后在给我推荐食谱时，请排除相关食材。”

*当 ChatGPT 成功记录下这些信息时，你通常会在对话框上方看到一个“Memory updated（已更新记忆）”的提示。*

## 如何管理和删除 ChatGPT 的记忆？

记忆功能虽然方便，但有时候你可能希望删除某些过时的信息，或者不想让它记住某些涉及隐私的内容。你可以轻松地管理这些记忆。

### 1. 直接在对话中修改或删除
如果你发现 ChatGPT 记错了，或者你改变了偏好，可以直接在对话中告诉它：
*   “忘记我之前说的我是素食主义者。”
*   “更新记忆：我现在主要使用 TypeScript 而不是 JavaScript 了。”

### 2. 在设置中集中管理
如果你想查看或清理所有记忆，可以通过设置界面进行操作：
1. 点击左下角的**头像**，选择 **Settings（设置）**。
2. 找到 **Personalization（个性化）** 选项卡。
3. 点击 **Manage Memory（管理记忆）**。
4. 在这里，你可以看到 ChatGPT 为你记录的所有信息列表。点击每条记忆旁边的垃圾桶图标即可将其**删除**。
5. 如果你不想使用这个功能，也可以在这个页面直接**关闭 Memory 功能**的开关。

## 常见问题解答 (FAQ)

### Q1: 记忆功能和自定义指令有什么区别？
**自定义指令 (Custom Instructions)** 是一次性设置的全局规则，适合写下固定不变的背景信息。而 **Memory (记忆功能)** 是在对话中不断累积和更新的，更加灵活。两者结合使用效果最好。

### Q2: 记忆功能会跨设备同步吗？
会的。只要你登录的是同一个账号，在网页端和手机端产生的记忆是互通的。

### Q3: 临时对话也会产生记忆吗？
如果你使用的是“临时对话 (Temporary Chat)”功能，ChatGPT 就不会读取你过去的记忆，也不会在这个过程中产生新的记忆。这非常适合用来问一些一次性的、不想干扰 AI 认知的问题。
