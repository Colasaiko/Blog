Microsoft 365 Copilot 是微软推出的一项革命性服务，它将强大的大语言模型与你的 Microsoft Graph 数据（日历、电子邮件、聊天、文档、会议等）以及 Microsoft 365 应用（Word、Excel、PowerPoint、Outlook、Teams 等）深度结合，将你的语言转化为最强大的生产力工具。今天就来教你如何将 Copilot 接入并使用。


## 一、这个功能是什么？

Microsoft 365 Copilot 是一款深度集成在 Microsoft 365 应用程序中的 AI 助手。它不仅能回答问题，还能直接读取你的文档、邮件和会议记录，帮助你：
- 在 Word 中起草、改写和总结长文档。
- 在 Excel 中分析数据、生成图表和发现趋势。
- 在 PowerPoint 中根据提示词一键生成精美演示文稿。
- 在 Outlook 中总结长邮件并快速起草回复。
- 在 Teams 中实时总结会议要点并提取待办事项。

简而言之，它就像是一个随时待命的全能数字助理，极大地提升了你的办公效率。

## 二、在哪里可以找到？

要使用 Microsoft 365 Copilot，你需要满足以下条件并在相应位置找到它：

1. **订阅要求**：目前，Copilot 适用于特定订阅用户，例如拥有 Microsoft 365 商业标准版、商业高级版、E3 或 E5 许可证的企业用户，以及购买了 Copilot Pro 订阅的个人/家庭版用户。
2. **应用内位置**：一旦你的账户具备了权限，当你打开支持的 Microsoft 365 应用（如 Word、Excel、PPT）时，Copilot 按钮通常会出现在以下位置：
   - **开始（Home）选项卡**的右侧。
   - 在 Word 文档的空白处直接弹出的悬浮图标（通常在输入新段落时）。

## 三、怎么使用？

连接和使用 Copilot 的步骤非常直接，因为它是无缝集成的：

1. **登录账户**：确保你登录的 Microsoft 账户（或企业账户）已包含 Copilot 订阅。
2. **更新应用**：确保你的 Microsoft 365 桌面应用程序是最新版本，或者直接使用网页版（Web App）。
3. **打开应用**：以 Word 为例，新建或打开一个文档。
4. **唤醒 Copilot**：点击“开始”选项卡中的“Copilot”图标，会在右侧打开聊天面板；或者直接在文档空白处点击弹出的 Copilot 图标。
5. **输入提示词（Prompt）**：用自然语言告诉 Copilot 你想要做什么。例如：“帮我写一份关于第三季度销售情况的总结。”
6. **调整与采纳**：Copilot 生成内容后，你可以要求它进行修改（如“让语气更正式”）、缩短或扩展，满意后点击“保留（Keep it）”。

## 四、实际使用示例

### 1. Word 中的 Copilot
**目标**：快速起草一份项目提案。
**操作**：打开一个空白 Word 文档，点击 Copilot 图标，输入：“根据 [选择你的某份会议记录文档] 起草一份关于新产品发布的项目提案，包含背景、目标、时间表和预算概览。”Copilot 会自动读取该文档并生成初稿。

### 2. Excel 中的 Copilot
**目标**：分析销售数据。
**操作**：打开包含销售数据的 Excel 表格，点击右上角的 Copilot。输入：“将这些数据转换为图表，并总结出表现优质的三个地区。”Copilot 会自动生成图表并提供数据洞察。*(注：Excel 数据需要格式化为“表格”才能使用 Copilot)*。

### 3. PowerPoint 中的 Copilot
**目标**：根据文档制作幻灯片。
**操作**：打开 PPT，点击 Copilot。输入：“根据 [选择一份 Word 商业计划书] 创建一个 10 页的演示文稿。”Copilot 会自动提取文本、分层级生成幻灯片，甚至配上相关的设计和图片。

## 五、常见问题

**Q: 为什么我的 Word/Excel 里没有 Copilot 按钮？**
A: 请检查以下几点：
1. 确认你的账户是否购买并分配了 Copilot for Microsoft 365 或 Copilot Pro 许可证。
2. 确保你的应用已更新到最新版本。
3. 检查你登录的账户是否正确。
4. 有时需要重启应用或重新登录账户才能生效。

**Q: Copilot 会泄露我的公司机密数据吗？**
A: 对于企业用户，Microsoft 365 Copilot 遵循 Microsoft 现有的隐私、安全和合规性承诺。你的数据（包括提示、回复和业务数据）不会用于训练微软的基础模型，并且在组织内部受到严格的权限控制。

**Q: 为什么 Excel 里的 Copilot 无法点击（灰色）？**
A: Excel 中的 Copilot 目前要求你的数据必须格式化为“表格”（按 Ctrl+T），并且文件必须保存在 OneDrive 或 SharePoint 上。

## 六、使用时需要注意什么？

- **提示词（Prompt）的质量决定输出的质量**：尽量提供清晰、具体的指令，包含背景信息、期望的格式和语气。
- **保持人工审核（Human in the loop）**：Copilot 可能会产生幻觉或错误。始终仔细检查它生成的数据、事实和语气，不要盲目直接发送或汇报。
- **文件存储位置**：为了让 Copilot 能够跨应用读取其他文件（例如让 PPT 读取 Word），这些文件通常需要保存在云端（OneDrive 或 SharePoint），并开启自动保存。
- **语言支持**：虽然 Copilot 支持多种语言，但在英语环境下的表现往往是最优的。中文支持正在不断完善中。
