在日常使用 AI 的过程中，我们不仅希望 Claude 能给出自然语言的回答，更希望它能输出直接可用、可以直接复制到 Excel、代码或数据库中的结构化数据。将 Claude 作为一个“数据清洗”或“数据转换”的流水线节点，可以极大地提升工作效率。

今天就来教你如何通过优化 Prompt（提示词），让 Claude 稳定、准确地按照指定格式（如 JSON、Markdown 表格、CSV 等）回答。

## 为什么需要结构化输出？

普通的自然语言输出虽然易于阅读，但难以被程序解析或进一步处理。如果你需要：
- 将多段文本提取为字段并存入数据库
- 把杂乱的数据整理成清晰的对比表格
- 快速生成用于开发的模拟数据（Mock Data）

那么，强制 Claude 按照指定的格式（如 JSON 或表格）输出，就是你的必修课。

## 核心技巧：明确指令与限定标签

要让 Claude 100% 遵守格式要求，关键在于消除歧义，并使用 XML 标签来框定输出范围。Claude 对 XML 标签非常敏感，这是它的强项。

### 1. 让 Claude 输出标准 JSON

如果你需要 Claude 提取文本信息并输出 JSON，除了告知所需的字段结构外，最好加上严格的限制，避免它在 JSON 前后输出无关的废话（如“好的，这是你要的 JSON：”）。

**Prompt 示例：**

```text
你是一个数据提取专家。请从下面的文本中提取用户信息。

要求：
1. 必须且只能输出一个合法的 JSON 对象。
2. JSON 必须包含字段：name (字符串), age (数字), skills (数组)。
3. 不要输出任何多余的解释、寒暄或 Markdown 代码块包裹（即不要包含 ```json 和 ```）。
4. 将最终的 JSON 输出在 <result> 标签内。

待处理文本：
"我叫张三，今年28岁，擅长Python、数据分析和机器学习。"
```

通过这种方式，你可以用程序自动截取 `<result>` 标签内的内容，并通过 `JSON.parse()` 解析，实现完美的自动化流水线。

### 2. 让 Claude 生成 Markdown 表格

Markdown 表格非常适合阅读，也可以轻松粘贴到 Notion、飞书等支持 Markdown 的文档中。

**Prompt 示例：**

```text
请帮我对比 iPhone 15 Pro 和 Samsung Galaxy S24 Ultra。

要求：
1. 请以 Markdown 表格的形式输出。
2. 表格的列名应包含：对比维度、iPhone 15 Pro、Samsung Galaxy S24 Ultra、胜出者。
3. 对比维度应包含：屏幕、处理器、重量、起售价。
4. 在表格前后，只简短给出 1 句话总结，不需要过多的解释。
```

### 3. 让 Claude 输出 CSV 格式

CSV 格式是处理大量数据并导入 Excel 的最佳格式。

**Prompt 示例：**

```text
请将以下乱码般的账单数据整理为标准的 CSV 格式。

要求：
1. CSV 包含表头：日期,消费项目,金额,货币。
2. 请直接输出 CSV 内容，使用逗号分隔，不要包含任何多余文字或 Markdown 标记。
3. 请将输出包裹在 <csv> 标签内。

账单数据：
[...输入你的原始数据...]
```

## 常见问题解答 (FAQ)

### 为什么 Claude 有时还是会输出解释性废话？

尽管提示词里写了“不要输出多余解释”，AI 有时仍会犯错。优质的解决方法是**提供一个少数示例（Few-Shot）**，或者**严格要求将结果包裹在 XML 标签（如 `<result>`）中**，这样你就可以通过正则表达式轻易提取出你要的纯净数据。

### Claude 输出的 JSON 经常少闭合括号，怎么办？

当数据量过大，超过了 Claude 的单次输出 Token 限制时，JSON 就会被截断。建议：
1. 将大任务拆分成小任务分批发送。
2. 如果看到截断，回复“请继续”，然后手动将两段文本拼接。
3. 使用具有更大输出窗口的模型版本。

### 可以让 Claude 模仿我的自定义格式吗？

可以！你只需要在 Prompt 中给出 1-2 个标准的输入输出示例（Few-shot prompting）。Claude 的上下文学习能力极强，只要有例子，它就能完美模仿任何复杂的自定义数据格式。
