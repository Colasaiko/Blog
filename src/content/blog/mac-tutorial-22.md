## 1. 什么是 DNS？

DNS（域名系统）相当于互联网的地址簿，它将你输入的域名转换为计算机能够理解的 IP 地址。

## 2. 为什么需要客户端 DNS 设置？

在复杂的网络环境中，默认的运营商 DNS 可能会面临解析过慢或遭到污染的问题。此时，Mac 客户端可以通过内部接管 DNS 查询来解决这些痛点。

### DNS 污染
某些网络环境下，DNS 服务器可能会返回错误的 IP 地址，导致网站无法访问。

## 3. 客户端如何处理 DNS？

- **Fake-IP 机制**：客户端在收到 DNS 请求时，直接返回一个虚拟 IP（Fake-IP），从而快速建立连接。只有在需要真实连接时才在远端进行实际解析。这样大大减少了网络延迟。
- **解析分流**：根据规则，国内域名使用本地无污染的 DNS（如 119.29.29.29），而其他域名则交由远程节点解析。

## 4. 设置建议

对于初学者，建议保持客户端默认的 DNS 分流或 Fake-IP 设置即可，这通常能提供最佳的解析速度和安全性。
