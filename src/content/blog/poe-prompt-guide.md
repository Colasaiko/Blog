在使用多模型平台 Poe 时，掌握高效的 Prompt（提示词）编写技巧是获取高质量回答的关键。针对不同类型和侧重点的 Bot，我们需要的提问策略也有所不同。


## 一、这个功能是什么？

在 AI 工具中，“写 Prompt” 就是向 AI 表达你的需求，通过输入具体的指令、问题或上下文，引导大语言模型（如 GPT-4、Claude 3 等）输出你期望的结果。在 Poe 中，由于你可以随时切换不同架构和特性的模型（Bot），因此针对不同模型“因地制宜”地编写 Prompt，能够大幅提高工作和创作效率。

## 二、在哪里可以找到？

你可以在 Poe 平台的任何聊天界面中输入你的 Prompt：
1. 打开 Poe 应用或网页端。
2. 在左侧边栏选择你想要对话的 Bot（例如 Claude-3-Opus 或 GPT-4o）。
3. 页面下方的输入框即是编写和发送 Prompt 的地方。

## 三、怎么使用？

编写高效 Prompt 的通用技巧如下：

1. **明确目标和角色设定**：
   - 首先告诉 AI 它应该扮演什么角色（例如“你是一位拥有20年经验的高级 Python 工程师”）。
   - 清晰表达你的最终目的。
2. **提供充足的背景和上下文**：
   - 给出与问题相关的必要背景信息，避免让 AI 靠猜。
3. **结构化你的输入**：
   - 使用 Markdown 语法、序号、或者特殊符号（如 `###`、`"""`）将指令、参考内容和输出要求隔开。
4. **明确输出格式**：
   - 指定希望得到的结果形式（例如“请用表格展示”、“输出 JSON 格式”、“分点列出，不超过300字”）。
5. **分步提问（Chain of Thought）**：
   - 对于复杂任务，不要试图在一个 Prompt 中完成。可以先让 AI 制定大纲，再逐段扩写；或者要求 AI “请一步步思考（Let's think step by step）”。

针对不同模型的特性，还可以进行微调：
- **Claude 系列**：擅长长文本处理和细腻的文本创作。可以将 Prompt 重点放在设定语气和提供长篇参考资料上。
- **GPT 系列**：逻辑推理和代码编写能力极强。在结构化指令和多步骤逻辑任务上表现更好。

## 四、实际使用示例

### 示例 1：用于编程和代码问题
**差的 Prompt**：帮我写个贪吃蛇游戏。
**好的 Prompt**：
> 你是一位经验丰富的前端开发工程师。请使用 HTML5 Canvas 和纯 JavaScript (ES6) 编写一个经典的贪吃蛇网页游戏。
> 要求：
> 1. 代码包含详细的中文注释。
> 2. 游戏需要有计分板，吃到食物得 10 分。
> 3. 撞到墙壁或自己的身体则游戏结束，并显示“Game Over”。
> 请将 HTML、CSS 和 JavaScript 代码整合在同一个 HTML 文件中输出。

### 示例 2：用于文章创作和润色
**差的 Prompt**：帮我写一篇关于人工智能的博客。
**好的 Prompt**：
> 请你扮演一位科技专栏作家，为我的个人博客写一篇文章，主题是“普通人如何在日常生活中利用 AI 提高效率”。
> 写作要求：
> - 语气轻松、幽默，像在和朋友聊天。
> - 文章结构包含：引言、3个具体的应用场景（如自动化处理邮件、快速整理会议纪要、智能辅助写作）、结尾总结。
> - 字数在 800 字左右。
> - 请使用 Markdown 格式排版。

## 五、常见问题

**Q：为什么我写的 Prompt，不同的 Bot 给出的答案相差很大？**
A：因为不同的底层模型有不同的训练数据和对指令的理解偏好。一个在 GPT-4 上表现极好的 Prompt，在 Claude 上可能需要稍微调整表述方式（比如 Claude 更喜欢将参考资料放在特定 XML 标签 `<context>` 中）。

**Q：Poe 会限制我输入 Prompt 的长度吗？**
A：会受到上下文窗口（Context Window）的限制。不同的 Bot 支持的 token 数量不同（例如部分模型支持 100k 甚至 200k 的上下文）。如果超出限制，Bot 会提示或截断输入。

**Q：我可以直接用中文写 Prompt 吗？**
A：完全可以，绝大多数主流模型都具备极强的中文理解能力。不过对于某些极度垂直或新发布的小众模型，使用英文 Prompt 有时能获得更准确的响应。

## 六、使用时需要注意什么？

1. **隐私安全**：不要在 Prompt 中输入个人敏感信息、公司机密代码或未公开的商业数据。
2. **避免歧义**：尽量使用具体的数据和确切的词语，避免使用“稍微长一点”、“更好看一点”这种主观且模糊的词汇。
3. **及时修正（Prompt 迭代）**：如果 AI 第一次给出的答案不符合要求，不要直接放弃，尝试指出它的错误或补充忽略的细节（例如：“你忽略了要求 2，请重新生成”）。
