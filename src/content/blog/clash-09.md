很多人在 Clash 界面看到「直连模式」（Direct Mode）时都会产生疑问：开启代理软件本就是为了代理，为什么软件还要专门提供一个完全不走代理的模式？实际上，直连模式是排查网络故障、临时免关闭软件访问局域网和国内内网服务的绝佳工具。

当你在 Clash、Shadowrocket 等代理客户端的控制面板上，看到除了“规则（Rule）”、“全局（Global）”之外，还有一个叫做“直连（Direct）”的选项时，你可能会感到疑惑：我打开这个代理软件不就是为了“走代理”吗？为什么软件还要专门提供一个“不走代理”的模式？这个模式到底有什么用？

这篇文章将为你详细拆解“直连模式”的概念、工作原理以及它在实际网络环境中的重要应用场景。

## 基本概念

“直连模式”（Direct Mode），顾名思义，就是**直接连接**。

在计算机网络术语中，直连意味着你的设备（手机、电脑、路由器等）在向互联网上的某个服务器发起请求时，**不经过任何代理服务器的中转，而是直接由你本地的网络运营商（如中国电信、中国联通、中国移动）负责将数据包发送给目标服务器**。

当你将代理客户端（例如 Clash）的工作模式完全切换为“直连模式”时，实际上就等于把这个代理软件变成了一个“透明人”。虽然软件还在后台运行，甚至还在接管你系统的网络流量，但它收到所有的流量后，唯一的动作就是：原封不动地放行。

打个比方，如果你的网络数据是一个个快递包裹：
- **规则模式**：快递分拣中心，国内包裹交给顺丰（直连），国外包裹交给国际物流（代理）。
- **全局模式**：所有包裹，不管寄到哪里，统统交给国际物流（代理）去绕一圈。
- **直连模式**：快递分拣中心直接罢工，所有包裹不管去哪，全部直接交给你楼下的普通邮局（本地网络运营商）。

因此，在直连模式下，你无法访问任何被中国大陆防火长城（GFW）封锁的网站，如 Google、YouTube、Twitter 等。你的网络体验和完全没有开启代理软件时是一模一样的。

## 进一步理解：直连模式的原理与表现

要理解直连模式，我们需要稍微了解一下代理客户端接管流量的方式。

在电脑或手机上，为了实现代理加速，Clash 这类软件会创建一个本地的“虚拟网卡”或者“系统代理接口”。当你打开软件时，系统会将所有的网络请求先发送到这个本地接口，也就是交给了 Clash。

这就产生了一个问题：如果我现在不想走代理了，我只是想老老实实地用国内网络，我应该怎么做？

最简单粗暴的方法是：直接退出并关闭 Clash 软件。这样系统的网络请求就不再交给 Clash，自然恢复了本地直连。

但这并不总是最优雅的方法。有时候我们只是想**临时**关闭代理效果，或者我们想要利用代理软件的一些附加功能（比如 DNS 解析、局域网共享等），而不希望它改变流量的走向。这时，“直连模式”就派上用场了。

在直连模式下，流量依然会进入 Clash，但 Clash 内部的路由引擎收到流量后，会直接给所有流量打上 `DIRECT` 的标签，指示它们不要进入任何加密隧道路由（如 Shadowsocks、Vmess、Trojan 等协议），而是直接通过本机的真实网卡发送到公共互联网。

这带来的直接表现就是：
1. **你的 IP 地址变成了你真实的本地 IP**（比如你家里宽带的公网 IP，或者手机数据网络的 IP）。
2. **所有受 GFW 封锁的海外域名都将无法解析或无法建立连接，网页表现为“找不到服务器”或“连接超时”。**
3. **国内网站和 App 的访问速度达到你宽带的物理极限，且完全不会消耗你的机场订阅流量。**

## 实际应用：我们什么时候需要直连模式？

既然直连模式不能连接国际网络，那它存在的意义是什么呢？在实际使用中，直连模式有着非常多不可替代的应用场景。

### 1. 临时排查网络故障
这是直连模式最常见的使用场景。
我们在使用电脑或手机时，经常会遇到某个网页突然打不开，或者某个 App 突然无法加载图片的情况。此时，很多人的第一反应是“是不是我的代理软件或者机场节点出问题了？”

为了验证这一点，你不需要繁琐地去关闭软件、取消系统代理设置。你只需要一键将 Clash 切换到“直连模式”：
- 如果切换到直连模式后，该国内网页依然打不开，说明是你自己的宽带、路由器或者目标网站本身崩了，和代理软件无关。
- 如果切换到直连模式后，该国内网页瞬间恢复正常，说明是你之前的“规则模式”配置有误，或者你当时选中的代理节点出现了严重的延迟/丢包，导致被错误分流的国内流量卡死。

直连模式是网络故障排查中最快捷的“控制变量法”工具。

### 2. 玩国内网络游戏
对于竞技类网络游戏（如《英雄联盟》、《绝地求生》国服、《王者荣耀》等），网络延迟（Ping 值）和稳定性是至关重要的。
虽然“规则模式”理论上会将国内游戏的流量直连，但游戏客户端的网络请求极其复杂，有时会使用非标准端口，或者通过某些奇怪的 IP 发起连接，极容易被规则模式误判并走代理。一旦游戏流量走了代理节点，你的延迟可能会瞬间从 20ms 飙升到 200ms，甚至频繁掉线。

因此，许多硬核玩家在准备长时间游玩国内网游时，为了追求极致的稳定和绝对的安全，会选择直接将 Clash 切换为“直连模式”。这样既保留了软件在后台运行的便利性，又确保了游戏流量 100% 物理直连，杜绝任何误判的可能。

### 3. 使用对 IP 极其敏感的国内服务
某些国内企业级应用、银行 App、政务系统，或者像某些版权保护极其严格的国内流媒体（如 Bilibili 仅限中国大陆观看的番剧），它们对访问者的 IP 有极其苛刻的审查。

有时，即便是规则模式的 GeoIP 判定，也会因为数据库不够新，或者软件自身的 DNS 泄漏问题，导致目标服务器察觉到你的网络环境“不纯粹”。为了避免账号被风控封禁或拒绝服务，在进行大额转账、登录重要内部系统等操作时，切换到“直连模式”是最稳妥的防线。

### 4. 节省设备的电量和性能
在手机（如 iOS 上的 Shadowrocket 或 Android 上的 Clash）上使用代理软件时，即使是规则模式，由于需要不断地对每一个网络请求进行规则匹配和 DNS 解析处理，依然会消耗一定的 CPU 资源和电池电量。

如果你在长途旅行中，或者接下来的几个小时内明确知道自己只会使用微信、听本地音乐，完全不需要看外网，将代理客户端切换为“直连模式”，可以有效减少后台的运算负担，从而起到一定的省电作用。

## 常见误区

关于直连模式，新手最容易踩坑的几个误区如下：

### 误区一：打开了直连模式，依然能连接国际网络？
有的用户在点击了“直连模式”后，发现自己依然能正常访问 Google，于是大呼神奇。实际上，这大概率是因为你浏览器的**缓存**，或者你的浏览器安装了类似于 SwitchyOmega 这样的独立代理插件，该插件直接越过了系统层面的代理设置。也可能是因为你当前连接的网络环境本身就自带了代理加速功能（如软路由环境）。
记住，纯正的本地直连模式，在标准大陆网络环境下，是极少不可能访问外网的。

### 误区二：直连模式等于关闭软件？
这是一个容易混淆的概念。虽然表现上看起来都是无法走代理，但两者在系统底层是不同的。
当你完全退出 Clash 软件时，系统代理被清空，网络请求完全不经过 Clash。
而当你处于“直连模式”时，Clash 软件仍在运行，依然占据着系统代理的入口。这意味着你的流量依然在被 Clash 接管，只是它不对流量做加密和转发而已。这使得你可以随时快速地秒切回“规则模式”或“全局模式”，而无需重新启动软件。

### 误区三：机场节点里的“DIRECT”和工作模式里的“直连”是一回事吗？
在某些机场提供的订阅中，你会在节点列表里看到一个名为“DIRECT”或者“直连”的节点（通常带有特定图标）。而我们在文章中讨论的是整个软件级别的“直连工作模式”。
在规则模式下，你可以针对某些特定的网站设定策略为那个名为“DIRECT”的节点，这意味着只有这部分网站直连；而如果你把整个软件的大模式切换为“直连模式”，则意味着所有网站、所有节点选择都失效，强制全局物理直连。这两者的控制层级是不同的，但核心动作都是“不走代理”。

## 总结

“直连模式”就像是你代理软件上的一个“旁路开关”或者“休眠按钮”。

它虽然不能帮你跨越网络长城，但却是你日常网络使用中不可或缺的安全气囊和排障工具。它让你在需要纯粹国内网络环境时，能够做到一键还原，干净利落；又能在你需要放眼世界时，随时被唤醒，投入工作。

对于刚开始使用网络优化工具的朋友来说，不要因为直连模式不能“走代理”就忽视它。当你的网络出现诡异的卡顿、当你的国内游戏莫名掉线、当你需要登录重要的网银账号时，记得点开客户端的面板，轻轻切换到“直连模式”，很多问题都会迎刃而解。

理解了规则模式的智能和直连模式的纯粹之后，下一个我们需要攻克的概念，就是拥有绝对霸道力量的——“代理模式”（全局模式）。我们将在下一篇文章中为你详细解读。
