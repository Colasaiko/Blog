想要在手机上随时随地与 Grok 交流？目前，Grok 已经深度集成在 X（原 Twitter）的移动客户端中，无需下载独立的应用程序即可体验。


## 一、这个功能是什么？

Grok 手机端是 xAI 推出的 AI 助手在移动设备上的呈现方式。通过 X（原 Twitter）官方 App，Premium 和 Premium+ 订阅用户可以直接与 Grok 进行对话，获取实时信息、解答疑问、生成文本以及体验其独特的幽默感和无过滤的内容回答。

## 二、在哪里可以找到？

你不需要在应用商店搜索“Grok App”，因为它内置在 **X（推特）官方客户端**中。

1. 在手机应用商店（App Store 或 Google Play）下载并安装最新的 **X** 应用程序。
2. 登录你的 X 账号。
3. 确保你的账号已经订阅了 **Premium 或 Premium+** 服务。
4. 在 App 的底部导航栏正中间，或者侧边栏菜单中，找到带有“/”或“Grok”字样的专属图标，点击即可进入。

## 三、怎么使用？

1. **打开聊天界面**：点击底部导航栏的 Grok 图标进入对话界面。
2. **选择模型模式**：在顶部，你可以选择“常规模式（Regular Mode）”或“幽默模式（Fun Mode）”。幽默模式下的 Grok 会展现出其特有的机智和讽刺感。
3. **输入你的问题**：在底部的输入框中输入你想要询问的问题或指令。支持语音输入或文字输入。
4. **获取实时信息**：你可以直接询问当前正在发生的新闻或热门话题，Grok 会结合 X 平台上的实时推文进行总结和回答。
5. **管理对话历史**：在界面左上角或右上角的菜单中，可以查看历史对话、开启新的聊天。

## 四、实际使用示例

- **查询热点新闻**：“今天 X 上大家都在讨论什么科技新闻？给我总结一下。”
- **灵感创作**：“帮我写一条关于周末去露营的推文，带点幽默感。”
- **日常问答**：“解释一下量子计算的基本原理，用中学生的水平。”
- **实时事件**：“刚刚那场足球比赛的比分是多少？谁进的球？”

## 五、常见问题

**Q: Grok 有独立的独立 App 吗？**
A: 目前没有。Grok 作为 X 平台的一项高级功能，完全集成在 X 的官方应用程序中。

**Q: 免费用户可以使用手机版 Grok 吗？**
A: 目前 Grok 仅向 X 的 Premium 和 Premium+ 订阅用户开放。免费用户需要升级订阅才能使用。

**Q: 安卓和 iOS 都可以用吗？**
A: 是的，只要你的设备可以安装最新版的 X 客户端，不管是 iOS 还是 Android，都可以使用。

## 六、使用时需要注意什么？

- **订阅状态**：请确保你的 X 高级订阅处于激活状态，否则将无法看到或使用 Grok 入口。
- **网络连接**：由于需要实时获取 X 平台的数据并进行推理，使用时需要保持良好的网络环境。
- **信息核实**：虽然 Grok 拥有访问实时信息的优势，但 AI 生成的内容仍有产生幻觉的可能，对于关键事实和重要决策，建议进行多方核实。
