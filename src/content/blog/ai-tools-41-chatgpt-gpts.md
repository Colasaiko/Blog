## 什么是 ChatGPT GPTs？

如果你觉得自己写出来的 Prompt 总是差点意思，或者每次都要重复输入长串背景信息，那么 **GPTs（自定义 GPT）** 就是为你量身定制的功能。GPTs 是 OpenAI 推出的一种定制化 ChatGPT 机器人。用户可以将特定的指令、专属知识库（如 PDF 文档）以及特定技能（如联网搜索、代码解释器、外部 API 接口）打包，创建一个专门用于特定任务的 AI 助手。

最棒的是，你不需要自己从头做一个！在 GPTs 商店里，有成千上万个由全球顶级玩家制作并分享的 GPTs。不管你是要画图、写代码、分析财报，还是写自媒体文案，都可以直接“白嫖”别人的劳动成果，一键解锁各种超强专业能力。

## 如何在 GPT 商店中寻找并使用 GPTs？

使用别人做好的 GPTs 非常简单，只需几步即可开始你的效率飞跃之旅：

1. **进入 GPT 商店 (Explore GPTs)**：在 ChatGPT 的左侧边栏，点击“Explore GPTs”进入商店。
2. **搜索特定需求**：商店里对各类 GPT 进行了详细的分类（如 DALL·E 绘图、写作、效率、研究与分析、编程等）。你也可以在搜索框里直接输入你的需求，例如输入“Logo design”、“PDF analysis” 或者“Python coding”。
3. **选择并使用**：在搜索结果中，选择使用人数多、评分高的 GPT。点击进入后，你会发现这个对话窗口自带了制作者设定好的几个开场问题。你只需要像正常聊天一样跟它说出你的需求，它就能展现出极度专业的输出效果。

例如，使用专门的“Logo Creator” GPT，你只需输入“帮我设计一个极简风格的咖啡店 Logo”，它就会根据内建的专业设计提示词自动调用 DALL·E 为你生成高质量的设计图；使用专门的“PDF Reader” GPT，你可以直接上传几十页的行业报告，让它帮你总结核心要点。

## 注意事项：网络代理与外部 API

在使用一些功能复杂的 GPT 时（例如能帮你查机票、读网页、调用外部数据库的 GPTs），它们通常会**通过 Actions 调用外部第三方 API**。

这里需要特别注意网络连通性问题。如果你的代理规则（Proxy 规则）拦截了这些 GPT 尝试访问的外部 API 域名，或者你的代理节点本身被该外部服务屏蔽，**ChatGPT 就会在对话中报错**，提示无法连接或请求失败。因此，当你发现某个本该起作用的联网 GPT 持续报错时，建议检查你的代理软件，尝试将该外部域名加入直连规则，或者开启全局模式进行测试。

## 常见问题 (FAQ)

**Q: 免费版 ChatGPT 可以使用 GPTs 吗？**
A: 目前 OpenAI 已经向免费用户开放了 GPTs 的使用权限。不过，如果你想创建并发布自己的专属 GPT，通常还是需要 Plus 订阅。

**Q: 别人做的 GPT 会偷看我的数据吗？**
A: 当你使用别人创建的 GPT 时，你的对话内容不会直接分享给 GPT 的创建者。但如果该 GPT 启用了第三方 API Action（需要向外部发送数据以获取结果），在第一次发送请求时，ChatGPT 通常会弹出一个确认授权框，提醒你数据将被发送到特定的第三方网站，此时你可以自行判断是否授权。

**Q: 我也可以自己做一个这样的专属机器人吗？**
A: 当然可以！点击“Create”按钮，你只需要用大白话跟系统描述你想要一个什么样的机器人，设定好头像和名字，上传一些专属文档，你就能在几分钟内轻松拥有属于自己的专属定制 GPT。
