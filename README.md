## ☁️ Cloudflare 生产环境部署

项目采用前沿的 Serverless 形态，完全托管于 Cloudflare 边缘计算平台。

- **框架支持**：通过 Astro 提供的官方 Cloudflare Adapter (`@astrojs/cloudflare`) 进行灵活的混合渲染适配。
- **计算逻辑**：路由承载与后台接口部署运行于全球分布式的 Cloudflare Workers 节点。
- **持久存储**：核心高频数据（如评论）存放于原生支持的 Cloudflare D1 (Serverless SQLite)。
- **部署发布**：发布指令及数据库迁移完全依赖于 Cloudflare 的官方 `wrangler` CLI 工具链链。
- **生产网站**：[https://bestjichang.com](https://bestjichang.com)

## 📂 项目结构

遵循清晰纯粹的工程结构：

```text
.
├── migrations/         # Cloudflare D1 数据库 SQL 迁移演进记录
├── public/             # 静态公共免编译资源、Logo、robots.txt 及忽略清单
└── src/
    ├── components/     # Astro UI 无头状态及共享组件库
    ├── config/         # 站点元信息、SEO 常量及全站静态配置
    ├── content/
    │   └── blog/       # 严谨校验 schema 的 Markdown / MDX 元数据源
    ├── data/           # 零碎静态数据字典与本地备份文件
    ├── layouts/        # 高度复用的页面布局包装模板
    ├── pages/          # 路由映射主体及后台接口 (SSR / 混合端点)
    ├── styles/         # Tailwind CSS 全局入口规则
    └── utils/          # 独立提纯的通用工具方法库
├── astro.config.mjs    # Astro 生态链构建及外部 Adapter 组合配置
├── wrangler.jsonc      # Cloudflare Workers/D1 上云及本地模拟器挂载核心文件
├── package.json        # 核心依赖清单及 npm 执行指令定义
└── tsconfig.json       # TypeScript 解析与严格编译约束
```

## 🗄️ Database / Migration

在本地开发及云端正式部署时，本项目均使用基于代码定义的 Migrations 来维持数据库 Schema 的一致性。

- 各个阶段的 SQL 变动记录统一维护于项目根部的：`migrations/` 目录。

## 🔐 Environment Variables

为了代码仓库的长期安全性，本项目严格遵循敏感信息硬性隔离原则：

- 本地所需的开发调试与敏感调用环境变量被要求独立配置于：`.env` 或 `.env.*` 系列文件中。
- 所有 `.env` 后缀的文件已经通过根目录的 `.gitignore` 在源码层面被排除，无法提交至 Git。
- 在任何二次开发活动中，请绝对避免将真实的 API 校验令牌或 D1 Binding ID 硬编码写入明文代码层。

## ❓ FAQ

### 这个项目是什么？
这是 **好机场博客** ——一个前沿网络工具介绍、节点线路评测及优质应用推广的高性能内容聚合平台。

### 网站主要提供什么内容？
深耕于：全网优质机场实测与甄选、多平台客户端配置教程（特别是 Clash 系）、新奇网络工具赏析、AI 聚合与生产力辅助、VPS 纯净服务器导购，以及基础网络运维技巧和长文教程。

### 网站使用什么技术栈开发？
应用层利用了强大的 `Astro` 配合 `TypeScript`，UI 系统统一采用原子化 `Tailwind CSS` 构建。云端边缘逻辑委托给 `Cloudflare Workers` 进行拦截转发，数据持久化依托 Serverless SQLite 架构引擎 `Cloudflare D1` 落地。

### 评论数据存在哪里？
所有涉及用户留言交流的数据皆通过后台鉴权 API，安全并永久地保存在了 `Cloudflare D1` 数据库实体内。

### 文章撰写使用什么格式排版？
每一篇沉淀的技术博客均使用最极客的 `Markdown` 以及在支持扩展 JSX 语法的 `MDX` 原生格式，实现了排版的清晰、跨平台迁移的高容错以及内嵌交互组件的强扩展性。

### 网站目前是否全面开源？
当前代码库暂无明确的广泛共享开源协议许可。 License information has not been specified yet.

### 我可以 Clone 下来自己部署一套吗？
在准备完毕相应的 Cloudflare 个人账号及 D1 数据库额度后，仅需要修改 `wrangler.jsonc` 对应绑定并在环境变量区写入必要的本地 Secret，即可依托项目内部完善的配置文件利用 Wrangler 实现部署。
