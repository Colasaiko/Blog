# BestJichang IndexNow Workflow

This document outlines the standard operating procedure for notifying search engines (IndexNow) after changes are made to the site.

## Principles
1. **DO NOT submit during the build process.** `npm run build` is for generating static assets. Deployment happens independently via Cloudflare Pages.
2. **DO NOT submit the entire sitemap every time.** IndexNow is strictly for URLs that have been added, updated, or deleted. Submitting 400+ unmodified URLs repeatedly harms API quota and search engine trust.
3. **DO NOT assume deployment is complete immediately after Git Push.** Cloudflare Pages requires 1-3 minutes to build and deploy.

## Correct Workflow

### Step 1: Make Changes
Modify your content, layouts, or static pages locally.

### Step 2: Build & Verify (Local)
Ensure the site builds successfully and passes SEO checks:
```bash
npm run build
```

### Step 3: Commit and Push
```bash
git add -A
git commit -m "Your commit message"
git push origin main
```

### Step 4: Wait for Deployment
Wait ~2 minutes and verify that your changes are live by checking the actual URL in the browser (e.g. `https://bestjichang.com/`).

### Step 5: Get Changed URLs
Run the helper script to detect which pages were actually modified based on Git diff:
```bash
node scripts/get-changed-urls.js
```
*Note: If global templates (Header, Footer, Layouts) are modified, the script will warn you. You must manually decide which core URLs to push.*

### Step 6: Submit to IndexNow
Pass the modified URLs explicitly to the IndexNow script:
```bash
npm run indexnow -- https://bestjichang.com/ https://bestjichang.com/brands/
```
Or use the output generated by Step 5 directly.

The script will verify the IndexNow key is accessible on the live site before submitting.

## Sitemap Lastmod Rules
- **Blog Posts**: `lastmod` is automatically derived from the `pubDate` or `updatedDate` in the frontmatter. Do not blindly bulk-update dates without actual content changes.
- **Static Pages (/, /brands, etc.)**: `lastmod` is managed via `src/data/static-lastmod.json`. Update the date string in this file ONLY when you make significant changes to these pages.
